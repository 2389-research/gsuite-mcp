Install

One command

$ brew install 2389-research/tap/gsuite-mcp

Or build from source: go build ./cmd/gsuite-mcp

Setup

Four steps, then you're done

  1. Create OAuth credentials

    Go to Google Cloud Console. Create a project, click + CREATE CREDENTIALS, pick OAuth client ID, select Desktop app.

    Download the JSON and save it:

    ~/.config/gsuite-mcp/credentials.json

  2. Enable the APIs

    Click "Enable" on each:

    Gmail · Calendar · People · Tasks

  3. Authenticate

    $ gsuite-mcp setup

    Opens a browser. Sign in with Google. Token saved locally, you only do this once.

  4. Add to your AI client

    For Claude Code, one command:

    $ claude mcp add gsuite gsuite-mcp -- mcp

    Use --scope user to make it available across all projects:

    $ claude mcp add gsuite gsuite-mcp --scope user -- mcp

    For Claude Desktop or other MCP clients, add this to your config:

    {
  "mcpServers": {
    "gsuite": {
      "command": "gsuite-mcp",
      "args": ["mcp"]
    }
  }
}

    Done. Your AI works with your Google account now.

Multiple accounts

Work and personal, side by side

Connect as many Google accounts as you need:

$ gsuite-mcp setup --account work $ gsuite-mcp setup --account personal

Then just say which one you mean:

"Check my work email for anything urgent"
"What's on my personal calendar this week?"

Every tool accepts an optional account parameter. Without it, the default account is used.

$ gsuite-mcp whoami --account work Account: work Email: harper@2389.ai Messages: 4210 total Threads: 1847 total
Capabilities

What it does

33 tools across four Google APIs.

Gmail

Read, search, send, draft, label, trash, delete. CC and BCC supported.

Calendar

List, view, create, update, and delete events across your calendars.

Contacts

Search, browse, create, update, and delete contacts via the People API.

Tasks

Manage task lists and individual tasks. Create, update, complete, delete.

Built-in workflows

The server ships with prompts your AI picks up automatically:

  • Triage and organize unread email
  • Compose emails with proper threading
  • Schedule meetings around availability
  • Summarize your calendar
  • Review and organize pending tasks
  • Break goals into task lists
  • Look up contact details
  • Add contacts from email threads

Live data

MCP resources give your AI quick context: today's calendar, upcoming events, unread mail, current drafts, tasks due today, overdue tasks.
